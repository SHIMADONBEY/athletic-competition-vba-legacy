# athletic-competition-vba-legacy

このプロジェクトは陸上競技の大会運営管理を目的としたExcel VBA 製のレガシーマクロです。

## 開発の目的

陸上競技の記録集計業務の負担を軽減するため、エントリー選手のチーム、エントリーデータの管理から出場種目への振り分けまでを一貫して行うツールとして開発した。

## 技術スタック

- Excel VBA (Excel 2016の動作を想定)
- UI: Excel Worksheets.
- 開発環境: Visual Basic Code + XVBA

## 開発期間

2024年7月～2024年11月

## できること

- エントリーしたチームの管理
- エントリーした選手の管理
- 出場種目ごとの振り分け（トラック競技の出場者のみ）

## 作ろうとして挫折したこと

- チーム対抗得点の自動集計機能
- 申請CSVデータの一括出力
- チームと選手の紐づけ
- Top8一覧表の集約機能

## 開発挫折の経緯

- 実際の記録情報処理は複数人体制で行うことが普通であり、小規模な記録会では実用できたが、複数人で作業する大きい規模の競技会では実用できなかった。
- 操作してみて実際の運用課題で、データモデルを変えた時の変更コストが大きくなってしまった。
- クラスモジュールや永続化処理を共通ドメインパッケージ化したが、ドメインパッケージが肥大化してついていけなくなった。
